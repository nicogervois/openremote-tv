# Contributing

Keep the app completely free: no ads, subscriptions, paywalls, required accounts or tracking. Keep runtime control local. A new platform needs a separate adapter, protocol tests and explicit hardware status in the compatibility matrix. Never infer universal support from a manufacturer name.

Use typed Dart, keep parsing at network boundaries defensive, and run `dart format lib test`, `flutter analyze`, and `flutter test`. Do not commit credentials, local SDKs, build directories or home-network captures. Never remove certificate validation to work around a particular TV; document the model and discuss a scoped solution.

Manual Samsung testing is documented in `docs/samsung-testing.md`. Record failures as well as successful commands. Store publishing and paid developer services require separate owner setup; contribution does not authorize publishing a store release.
